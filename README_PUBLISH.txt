Free publishing option:
Use Netlify Drop at https://app.netlify.com/drop

How to publish:
1. Open https://app.netlify.com/drop
2. Sign in or create a free Netlify account.
3. Drag the whole project folder into the upload area.
4. Wait for Netlify to finish uploading.
5. Copy the generated website link ending in netlify.app.
6. Send that link as the actual project link.
